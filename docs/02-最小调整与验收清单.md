**目标：** 在 Windows 中运行 `day06-00`，使用独立数据复现课程主流程，并修正影响前后端对接的已确认问题。

**结构：** 保留现有 FastAPI 分层和前端 Vue 工程；使用独立 MySQL 库及 Redis 缓存前缀。修改集中在环境配置、接口字段和已有业务逻辑。

- 所有业务源码修改仅限 `day06-00`；课程原物料与旧 `day06` 保持原状。

## 验收需要关注的输入

1. 历史 ID 与新闻 ID 不相等：删除只能命中指定用户的指定历史记录，不能混用两种 ID。由任务 4 验证。
2. 缓存命中与未命中：新闻对外字段一致，详情浏览量仍增加，分类分页不串结果。由任务 3、5 验证。
3. 同一用户重复浏览同一新闻：更新时间，不能无意新增重复历史。由任务 6 验证。
4. 旧密码错误、令牌失效、新闻不存在：保留明确错误结果，不能把失败当作成功。由任务 6 验证。
5. 端口被占用、数据库目标已有数据、Redis 不可用：明确识别状态，不能自动使用旧端口或旧库。由任务 1、2、5 验证。
