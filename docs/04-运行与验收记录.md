## 浏览器与 PDF 对照

### 审查发现的五项问题修复

1. 令牌创建先锁定用户行，再锁定读取该用户的令牌；写入后提交。`uq_user_token_user` 保证每名用户只有一行令牌。
2. 历史写入采用同样的用户锁与最新数据读取；`uq_history_user_news` 保证每名用户对每篇新闻只有一行历史。
3. 历史本地缓存改为 `news_history:user:用户ID`，游客单独使用 `news_history:guest`。旧版共享缓存无法确认归属，因此丢弃；登录、注册和退出会清空内存历史。迟到的历史和资料响应核对账号令牌后才更新状态。
4. 详情加载捕获新闻 ID、请求序号、账号令牌和新闻数据；异步历史与收藏查询结束后重新核对，旧请求不能修改新新闻的星标。
5. 首页切换标签同步 `categoryId` 查询参数。真实浏览器验证：从分类页进入社会，切换国内，打开新闻 102，再返回，国内标签和新闻列表保留，URL 为 `/home?categoryId=3`。证据：[分类返回修复](screenshots/分类返回修复.jpg)。

数据库迁移：停止本项目服务后执行 `migrate_constraints.py`。使用临时账号构造两条令牌和两条历史，验证先备份、保留最新行、添加唯一约束；再次执行验证幂等，临时账号已清理。备份位于被 Git 忽略的 `logs/`，不输出令牌内容。新安装通过派生 SQL 自带约束；`init_db.py` 同时调用迁移以兼容已有课程库。

上述收藏竞态与账号请求失败场景使用确定性的延迟响应测试验证，没有在浏览器中人为制造网络故障。
